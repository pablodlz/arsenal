# graphql-endpoints.txt
#
# Paths to probe when the known GraphQL endpoint is protected but a second,
# forgotten one is not. On a real target the primary API sat behind Cloudflare
# while a dev host answered unfiltered — until it didn't, mid-investigation.
# Alternate endpoints on the *same* host are the cheaper version of that.
#
# Provenance: the /graphql, /api/graphql, /gql and versioned variants below were
# probed live (all 404 on that target). The rest are the standard surface across
# Apollo, Hasura, Relay, Graphene, Strawberry, WPGraphQL and Shopify-style APIs.
# Write-up: https://github.com/pablodlz/writeups/blob/main/web/graphql-phantom-success.md
#
# Probe with POST {"query":"{__typename}"} — a 200 with data.__typename confirms
# a live endpoint even when introspection is disabled. Then try GET with
# ?query={__typename}, since GET is frequently exempt from the CSRF and
# content-type checks applied to POST.
